### ⚙️ Production Systems & Engineering Impact

* **OLAP & Analytical Latency**: Tuned and optimized analytical queries across **70M+ records** using ClickHouse, cutting query latencies to **~30ms** in high-throughput production environments.
* **Event-Driven Integration Architecture**: Architected a decoupled hospital integration platform using Factory and Adapter patterns to ingest disparate healthcare data feeds, handling **100K+ events monthly**.
* **Cost-Aware Inference Pipelines**: Engineered dedicated intent-classification routing and RAG pipelines for conversational systems, cutting per-request token usage by **~90%** (7,000 → 700 tokens) while decreasing customer escalations.
* **Core Allocation & Transactional Engines**: Designed high-throughput appointment allocation and ranking engines, standardized microservice CI/CD pipelines, and reduced redundant schema topologies across distributed services.
